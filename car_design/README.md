# 3D Car Design

Parametric car design scripts, STL/OBJ model files, and CAD automation tools.

## Status: Planned

## Planned Components

- `models/` — STL and OBJ car model files
- `scripts/` — Blender/SolidWorks automation scripts
- `renders/` — Rendered output images

## Integration

Desktop tool integrations already exist in `desktop/tools/`:
- `blender.py` — Blender integration
- `autocad.py` — AutoCAD integration
- `solidworks.py` — SolidWorks integration
- `illustrator.py` — Illustrator integration

## Getting Started

1. Install Blender (or your preferred CAD tool)
2. Place model files in `models/`
3. Use scripts in `scripts/` for automated design workflows
